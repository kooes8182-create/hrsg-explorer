# 09. 미제공 자료 목록

아래 자료는 **제공되지 않았습니다.** 확보한 것처럼 구현하거나 표현하지 않습니다.
자료가 들어오면 이 표의 "확보 후 할 일"을 기준으로 명세를 먼저 고친 뒤 구현합니다.

| # | 자료 | 계획서상 용도 | 현재 대체 처리 | 확보 후 할 일 |
|---|---|---|---|---|
| 1 | 실제 플랜트 운전·설계 데이터 | 평가 입력 | 가상 DEMO 시나리오 + 사용자가 직접 입력 | 비식별 여부 확인 후 케이스 입력으로 사용 |
| 2 | 사내 데이터 요청 양식(스프레드시트) 전체 | 체크리스트 항목 | 계획서 범주 기반 **초안 30개 항목** (03 §3) | 항목·단위·필수 여부를 양식 기준으로 교체 |
| 3 | 비공개 계산 모델 (세정 실적 기반 산정 방식) | 현재 상태, 예상 손실, 회수 효과 | 실제 평가 경로는 **산출 불가** (`NotConnectedModel`). 별도로 공개 문헌 기반 **참고 추정**(GT 출력·열소비율 범위)만 제공 | 서버 전용 `PerformanceModel` 구현으로 연결, 응답·로그에 식 비노출 |
| 4 | 사내 세정 전후 성능 실적 데이터 | 계산 모델 기반 | 없음 | 모델 내부에서만 사용 |
| 5 | 가스터빈 모델별 운전 한계 참조표 | 정상/경보/트립 판정 | 판정 로직 없음. DEMO 시나리오 지정 상태만 표시, 게이지에 한계 구간 미표시 | 참조표 반영 및 판정 기준 명세화 |
| 6 | 필수 항목 확정 기준 | 평가 기능별 필수 여부 | **임시 기준** 표시 | 기준 확정 후 임시 표시 제거 |
| 7 | 핀치·어프로치 판정 기준값 | 열 회수 상태 점검 | **Phase 6**: IAPWS-IF97 로 참고 계산 + 문헌 일반 범위와 참고 비교 (판정 없음) | 이 설비 설계값·판정 기준 확보 시 교체 |
| 8 | 세정 공법 목록과 공법별 비용 기준 | 공법별 비용 비교 | 사용자가 공법 이름·비용·회수 출력을 **가정값**으로 입력 | 공법 목록·비용 근거 반영 |
| 9 | 협력사 기술 자료(브로슈어, 케이스 스터디, 점검·모델링 보고서) 비식별본 | AI 답변 근거 | AI는 케이스 체크리스트·계산 결과만 근거로 사용 | 비식별본만 서버에 두고 근거 인용 방식 명세화 (원문 노출 금지) |
| 10 | LLM API 키 | 실제 AI 질의응답 | 템플릿 기반 **데모 답변** | `.env` 에 키 설정, `LLMProvider` 구현 |
| 11 | 검증용 사례와 기대 결과 | 검수 #2 | DEMO 고정 기대값으로만 검증 | 사례별 회귀 테스트 추가 |
| 12 | 검수용 테스트 질문 20개 | 검수 #4 | 데모용 초안 20개 (07 §3) | 공식 질문 세트로 교체 |
| 13 | KPX SMP 자료 | 경제성 계산 | **Phase 6 일부 반영**: 확인한 육지 가중평균 SMP(월 2025-01~2026-09, 연 2022~2025)를 참고값으로 제공. 실시간 조회는 없음 | 시간별 Open API 연동은 인증키 필요 |
| 14 | 웹앱 수업 자료의 "Ⅲ 배포" 부분 | (배포는 이번 범위 외) | 해당 없음 | — |
