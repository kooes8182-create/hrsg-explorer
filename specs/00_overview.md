# 00. 개요

## 1. 목적

복합화력 발전소의 HRSG는 운전 중 가스측 튜브(핀 표면)가 오염되어 **차압과 굴뚝 온도가 오르고 발전 출력이 줄어듭니다.**
현장 엔지니어가 "지금 세정해야 하는가, 어떤 공법이 경제적인가"를 판단할 때 필요한
**데이터 준비 → 성능·경제성 검토 → 질의응답**을 한 곳에서 할 수 있도록 돕는 웹앱입니다.

이번 구현은 **가상 데이터로 로컬에서 실행되는 단일 사용자 데모(PoC)** 입니다.
실제 플랜트 판단에 사용할 수 있는 결과를 만들지 않습니다.

## 2. 사용자

- 복합화력 발전소 / HRSG 세정 업무 엔지니어 1명 (로컬 PC에서 혼자 사용)
- 로그인·권한 구분 없음

## 3. 범위

### 포함
| 기능 | 명세 |
|---|---|
| 평가 케이스 생성·선택 (체크리스트·입력·결과·질문 이력을 케이스 단위로 저장) | 01 |
| 평가 개요 (준비 상태, 평가 가능 여부, 다음 할 일) | 01 |
| 플랜트 데이터 요청 체크리스트 (계획서 기반 초안) | 01, 03 |
| 성능 평가: DEMO 시나리오 경로 / 실제 평가 경로(모델 미연동, 산출 불가) | 05 |
| 사용자 가정 기반 단순 경제성 계산 | 05 |
| 핀치·어프로치 입력 영역 (기준 미확보로 산출 불가 표시) | 05 |
| 게이지, HRSG 도식, 공법 비교 그래프 | 02 |
| AI 질문하기 (템플릿 기반 데모 답변, 향후 LLM 연결 구조) | 06 |
| 한국어 기본·영어 전환, 라이트/다크 모드, 반응형 | 02 |

### 제외 (구현 금지)
- 회원가입, 로그인, 사용자별 권한
- 실시간 센서 연동, 자동 제어
- 외부 배포, Docker
- 실제 LLM 호출 (구조만 준비)
- KPX SMP 자동 수집
- 수업 자료의 인사평가 예시 기능 전부
- 위 표에 없는 모든 기능

## 4. 메뉴와 사용 흐름

왼쪽 메뉴 4개 + 오른쪽 본문. 상단에 **현재 평가 케이스 선택기**와 **DEMO / 실제 평가 표시**가 항상 보입니다.

```
[평가 케이스 생성/선택]
        │
        ▼
1) 평가 개요 ──► 2) 데이터 준비 ──► 3) 성능·경제성 평가 ──► 4) AI 질문하기
   준비 상태       체크리스트          DEMO / 실제 / 가정 계산      케이스 데이터 기반
   다음 할 일      값·상태 입력        결과·도식·그래프            데모 답변
```

- 케이스가 하나도 없으면 모든 화면에서 "평가 케이스를 먼저 만드세요" 빈 화면과 생성 버튼을 보여줍니다.
- 화면을 이동해도 입력 중인 값은 유지되고, 저장한 값은 새로고침 후에도 복원됩니다.

## 5. 용어 (계획서 5장 기준 + 보충)

| 용어 | 설명 |
|---|---|
| HRSG | 가스터빈 배기열로 증기를 만드는 보일러(배열회수보일러) |
| 배압 (GT 배압) | 가스터빈 배기 압력. 오염 시 상승 |
| 차압 (HRSG ΔP) | HRSG 가스측 입구–출구 압력 차이. 오염으로 가스 통로가 좁아지면 상승. **배압과 다른 측정값**으로 다룸 |
| 굴뚝(스택) 온도 | HRSG를 빠져나가는 배기가스 온도. 오염 시 상승 |
| 핀치·어프로치 포인트 | HRSG 열 회수 상태를 나타내는 온도 차 지표 |
| SMP | 전력 도매 가격(계통한계가격). 이 앱에서는 **사용자 가정값**으로만 입력 |
| 평가 케이스 | 한 번의 검토 단위. 체크리스트·입력값·결과·질문 이력이 묶임 |
| DEMO | 명시적으로 고른 가상 시나리오의 고정 입력과 예시 결과 |
| 실제 평가 | 승인된 계산 모델을 쓰는 경로. **현재 미연동 → 산출 불가** |
| 사용자 가정 기반 계산 | 사용자가 넣은 가정값으로 한 단순 산술. 검증된 성능 예측이 아님 |
| 임시 기준 | 확정되지 않은 필수 항목 기준. 화면에 "임시 기준"으로 표시 |

## 6. 업무 규칙 (계획서 5장)

- 모든 수치는 **서버 계산 결과**에서만 나옵니다. AI(데모 답변 포함)는 숫자를 만들지 않습니다.
- 추정값은 보수적으로 제시하며, 근거가 없으면 산출하지 않습니다.
- 금지: 원문 문서·파일 노출, 고객사·발전소·개인 정보 노출, 내부 계산 방식 공개, 확인되지 않은 가격을 공식 가격처럼 제시

## 7. 계획서와 이번 요구사항의 차이 처리

이번 PoC 요구사항(사용자 지시)이 계획서보다 우선합니다.

| 계획서 내용 | 이번 처리 | 이유 |
|---|---|---|
| 사내 데이터 요청 양식 항목을 "모두 포함" | 체크리스트를 **"계획서 기반 초안"** 으로 표시. 전체 양식 재현이라고 표현하지 않음 | 양식 미제공 |
| 상태 색상 "정상·주의·위험" / 검수 시나리오 "정상→경보→트립" | 운전 상태는 **정상·경보·트립** 3단계, 색상+텍스트. DEMO 시나리오에서만 판정 표시 | 검수 시나리오와 일치, 실제 판정 기준 미제공 |
| "값을 바꾸면 화면이 즉시 반응" | DEMO 입력을 바꾸는 즉시 **"입력 변경으로 재평가 필요 / 실제 모델 미연동"** 으로 전환. 사용자 가정 경제성 계산은 값 변경 시 다시 계산 | 미연동 모델 결과를 지어내지 않기 위함 |
| 계산 모델 = 사내 실적 기반 비공개 산정 방식 | 실제 평가 경로는 항상 `null` + 사유 | 모델 미제공 |
| 가스터빈 모델별 운전 한계 참조표를 앱에 내장 | 내장하지 않음. 가상 모델 `DEMO-GT` 만 사용 | 참조표 미제공 |
| KPX SMP 공개 자료 | 자동 연동 없음. 사용자 가정값 입력 + "공식 가격 아님" 표시 | 이번 범위 외, 확인되지 않은 가격 제시 금지 |
| 검수 #2 "검증용 사례로 기대 결과 일치" | DEMO 고정 기대값 일치만 검증. 실제 사례 검증은 미완료 | 검증 사례 미제공 |
| 검수 #4 "테스트 질문 20개 정답률 80%" | 데모용 질문 20개 초안을 07 문서에 정의 | 질문 세트 미제공 |
| 질문하기: "기술 자료와 사례를 근거로 답한다" | 기술 자료가 없으므로 케이스의 체크리스트·계산 결과만 근거로 사용 | 협력사 기술 자료 미제공 |
